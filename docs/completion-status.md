## 仍不能声称“目标全部完成”的事项

1. 使用用户真实音频桥与账号验收实时语音；网页和 PCM 中继已完成并通过真实回环协议测试。
2. 在所选地域配置实际视频模型/API Key，并验证已有 dashboard、ring-hub、WeQ 与设备；原生适配器已实现，无须为了基本接入另建通用桥。
3. 在目标 Linux 环境验证 namespace 沙箱与 Docker 部署；在真实浏览器中做桌面/手机视觉和完整操作验收。
4. 项目级许可证由 owner 决定；不替用户选择。

上述事项单独保留为真实剩余工作。不能只因测试通过把它们打勾。没有修改生产部署、调用付费供应商或向真实账号发送测试消息。

## 本轮最终验证记录

- 完整 Python 回归：837 passed、1 skipped。唯一跳过项是当前受限宿主缺少成功降权权限；降权被拒的分类处理另有回归。
- 前端：15 项客户端/组件行为测试通过，TypeScript 检查与 Vite 生产构建通过。
- `scripts/build_release.py` 成功，wheel 内网页入口和静态资源均存在；真实本机 HTTP 验证 SPA 与资产返回 200。
- 原生 TCP PCM + WebSocket 音频往返、一次性票据、防重放、万相协议、dashboard/ring-hub、HTTP 外置插件、密钥遮蔽和禁止重定向均有测试。
- 当前浏览器与执行环境不能互访回环地址，未做桌面/手机浏览器视觉验收；Docker daemon 不可用，未实际启动 Compose；没有真实供应商或设备验收。

这些限制是验收条件未满足，不是用测试替身代替真实功能。下一次部署应先备份，再在测试账号/设备上按 deployment/service-bridges 文档逐条验收。
