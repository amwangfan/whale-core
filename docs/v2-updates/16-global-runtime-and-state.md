# 第 16 轮：全局运行锁、事务与动作一致性

检查两仓主线与现有 PR，基线无新增提交。扩大验证到完整 Python 测试发现与网页完整回归，发现 Windows 运行锁的 import 阻塞、POSIX-only 测试收集问题和缺少开发依赖。运行锁现在使用 Windows 字节锁/POSIX flock，保留原文件名与 CLI 独占行为；验证跨进程互斥与关闭释放。补齐项目虚拟环境中已声明的开发依赖，没有修改用户配置或运行地址。

内存与 SQLite 事务补充原子删除；内存事务读写返回独立数据，避免嵌套值修改后回滚失败。提取 ActionRecords，把真实回执和后台保留清理统一放进存储事务：清理在事务内重读，不能用陈旧快照覆盖刚到的真实终态；动作、反向索引和历史一起删除。收到冲突回包时，等待方拿到持久化的首个终态。

定向验证：运行锁、两种存储的并发/回滚/删除、清理竞争和真实网关回归共 64 项通过；网页完整回归 96/96。全局 Python 首次执行到 874 项通过时因 8 个失败、4 个环境错误停止，主要为 POSIX 权限、Linux launcher、Windows symlink 权限，以及旧测试夹具未包含新会话字段；这些结果保留，下一轮继续处理，未宣称完整全量通过。
