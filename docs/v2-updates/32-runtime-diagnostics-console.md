# 第32轮：网页设备与后台诊断闭环

本轮将31轮的清理诊断与记忆worker指标接到网页，而不重复28轮已有的读取预算/流式尾部。新增主导航“设备与后台”，页面按设备连接、动作记录清理、记忆后台任务分区。

设备展示登记数量、在线数量、配对/撤销/在线/离线状态及授权项数。清理展示本批检查/删除/待核对数量、耗时、是否有后续批次和清理时间，明确不是累计总量。记忆展示队列、完成/重试/失败、模型忙碌和提交拒绝计数，标明worker重建后计数重置。

两类请求独立展示，某一接口失败不阻塞另一块。每次读取15秒截止；刷新后旧请求取消且旧响应不可覆盖新快照。可选自动刷新在本次完成后10秒启动，不堆叠请求；页面隐藏暂停，卸载取消并移除计时器/监听。失败保留旧数据时显示“上次成功数据”和时间，不伪装为在线实况。旧核心缺少指标时显示不可用，不当作零值或健康状态。

后端现有GET /diagnostics增加memory_worker白名单计数，不返回证据、任务文本、租约令牌或异常正文；未装配/读取失败为独立状态，不影响原诊断报告。设备清理沿用已鉴权GET /devices。没有新增设备控制、删除或配置写入按钮。

前端104项通过，新增8项覆盖部分失败、挂起请求、陈旧提示、迟到响应、15秒超时、可见性暂停及卸载/禁用刷新。类型检查与生产构建通过；后端专项27项通过，完整结果在阶段交付记录。布局使用现有组件样式，窄屏降为单列；本机没有额外浏览器手工布局/真机验收，不将DOM测试等同于这些验收。

本轮不自动部署或重启用户服务。更新源码/安装包后运行，才能看到新导航。Mobile生产源码未改。
