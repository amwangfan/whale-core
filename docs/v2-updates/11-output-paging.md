# 第 11 轮：两端字节分页与完整输出读取

Mobile 增加 OutputPages：文件随机读取、48 KiB 单页预算、字节偏移/总长度/下一偏移、旧输出源适配。Agent2 提供三参数读取重载，NodeRuntime 优先绑定分页接口，保留旧单参数接口供现有调用使用。大观察文件不再先截取尾部；图片无需整体塞入一帧。

Core 提取共同的输出页解码与拼接，支持完整读取、UTF-8 跨页保真、总读取预算；检测坏偏移、页不前进、长度变化及源已截断，防止无限循环和把残缺输出当完整内容。

分页数据语义在 Mobile canonical PROTOCOL §7.4 落定并整体同步 Core 镜像，未新增信封字段或消息类型。

验证：Core 输出适配与分页 23 项通过；纯 Kotlin/JVM 文件分页与反射接线 7 项通过。验证包含超过 100 页的中文/表情/任意二进制拼接、EOF、非法参数、损坏分页和预算停止。本机只有 Java 8，隔离下载 Kotlin/JUnit 工具到 logs；未编译 Android 依赖的完整 APK，仍需 Android 构建及真机验收。
