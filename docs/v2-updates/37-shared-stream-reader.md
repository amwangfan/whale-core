# 第37轮：共享有界流式读取

事件流和聊天流共用readJsonEvents，沿用Core一行data:对应一个JSON对象的现有格式，不改服务端协议，也不声称实现任意多行SSE数据。统一处理UTF-8跨块、CR/LF、注释、无效及非对象JSON、EOF尾行。

单行最多1048576个JavaScript字符，超过后终止并清理，避免无换行响应无限积累；不是网络字节限制或整个对话输出限制。读取结束、异常、消费者提前离开及取消均释放reader；close后fetch迟到返回也不再发送事件回调。JSON解析与业务回调分开，业务回调异常不再当坏JSON吞掉。

网页129项、类型检查和生产构建通过，新增8项覆盖字节拆分Unicode、超长行、提前退出、已取消/在途取消、忽略fetch取消的迟到连接及回调异常。最终三轮回归见第39轮交付。
