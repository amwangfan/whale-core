# 第 14 轮：按会话结束请求与异步通知发送

查询、动作、设备确认共用登记/发送/等待/清理实现，等待项绑定实际连接。登记时在锁内检查当前会话及关闭状态，避免请求挂到已被替换的连接。

断线、撤销、主动断开、服务关闭统一结束该连接的等待项：查询返回 unavailable，确认返回未批准，动作返回 unknown；动作持久记录保留，迟到真实回执仍可对账。新连接的等待项不会被旧连接清理。发送中连接异常也走同一路径，避免 HTTP 请求一直等待原期限。

异步通知发布与撤回转在线程中执行同步 WebSocket 写入，避免阻塞 asyncio 调度；错误继续向原调用方传播。

验证：83 项会话/确认/回执及真实 WebSocket 回归通过，覆盖 30 秒请求在断线/服务关闭后及时结束、替换连接隔离、模糊发送失败、旧状态保留和通知发送线程。
