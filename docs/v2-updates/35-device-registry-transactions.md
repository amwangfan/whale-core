# 第35轮：设备注册状态事务化

配对申请、批准、吊销、删除、权限更新共用事务边界：读取最新状态后变更，成功审计和状态一起提交。SQLite BEGIN IMMEDIATE覆盖不同连接/注册表实例；内存存储用原有事务锁及回滚。仅使用事务KV接口写入，避免嵌套commit。被拒绝批准的审计在回滚后保留。

配对码尝试耗尽明确返回conflict，禁止保存冲突码；历史重复码拒绝批准，避免随机批准一台设备。配对显式scopes=[]保留零权限，只有None采用默认全集。非负整数TTL校验保留零秒立即过期行为。

设备列表改用现有前缀分页，每页500键，兼容旧keys后端。仍返回全部设备、仍需遍历device命名空间（包含动作子域），没有增加索引或迁移，也不宣称恒定成本。配对全局唯一检查在短事务内遍历设备，大规模设备部署仍需评估索引方案。

新增14项双后端测试，覆盖并发碰撞、同码批准只消费一次、撤销与权限更新竞争、审计失败回滚、旧重复码、零权限与跨页查询。相关54项通过，辅助函数收敛后注册/权限/新增44项再验证通过，最终全量见第36轮。
