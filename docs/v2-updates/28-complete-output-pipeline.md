# 第28轮：完整输出链路整合

本轮围绕文件来源、分页查询、完整组装和观察解析统一处理读取预算，而非继续只修单个字段。

Core完整读取增加默认60秒总时限和4096页上限，可通过read_output_complete的timeout_s/max_pages调整；时限最大24小时。每页查询使用剩余总时间与原15秒查询时限的较小值，超总时限映射expired，调用方取消仍保留CancelledError。已声明总长超过字节预算时首个响应即停止，不再传输到预算耗尽才拒绝。取消线程包装的同步查询不会强制终止线程，已发出的只读查询由其自身缩短后的等待时限收束，不会继续发后续页面。

Mobile抽取纯AgentOutputFiles，旧调用与分页共用引用白名单、目录映射、文件检查和实际读取。Agent2Module移除重复分支；规范化路径后检查父目录，拒绝指向目录外的文件。旧文本输出流式解码，只保留原字符尾部，内存随尾部上限和固定缓冲变化，不再先读整个大文件。文字、图片、缺失引用的返回形状保持；旧图片读取仍使用原完整字节返回方式，未声称已流式化图片。
