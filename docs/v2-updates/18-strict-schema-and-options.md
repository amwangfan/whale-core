# 第 18 轮：两端解析与参数一致性

Core 的轻量 schema 校验区分布尔值与数字，同时按 JSON Schema 规则接受整数形式的小数；枚举、常量和嵌套数组去重使用同一比较规则。数字范围在未声明 type 时仍生效，非法规则在加载阶段明确失败。开发测试用参考校验器交叉验证，不增加运行时依赖。

Mobile 严格解析 JSON，整数参数拒绝小数截断与溢出，直接编码/解码入口同样检查 UTF-8 帧大小。录制参数抽取为纯策略，错误字段、错误类型和超界数值不再静默使用默认值，正常默认值与既有功能保留。

验证：Core 相关测试 **107 passed**；Mobile 纯 JVM **117 passed**。包括参考 schema 对照、非法 JSON、整数精度、录制选项与大小边界。没有完整 APK 或真机验收结果。
