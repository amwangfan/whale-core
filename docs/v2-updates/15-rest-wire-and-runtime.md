# 第 15 轮：REST、协议帧和运行时接线边界

REST 查询/动作/设备确认提取共同参数解析：保留合法数字字符串、默认值、管理面 timeout 范围及 args 别名；拒绝 NaN/无穷大、布尔/小数计数、错误对象、错误 ID 类型。无效确认在创建挑战前被拒绝。显式空 scope、空任务 ID 不再偷偷变成默认值或被丢弃，交由 V2 契约检查；持久动作记录保留任务/运行/观察/关联 ID。

出站统一构造与编码，序号锁内编码一次，按 UTF-8 字节检查 256 KiB 帧预算，拒绝不可序列化数据和非有限数字。动作在占幂等键前完成相同预检。入站拒绝非标准 JSON 常量及超出有限浮点范围的数字；无效 ref_id 使用合法兜底 ID，保证错误帧本身可发送。

Mobile 补齐真实 Agent2Runtime 门面的三参数分页转发。分页显式协商 page_format=bytes.v1；未协商保留原 text/data_base64 输出，旧调用方不被强制切换。执行器注册改为按分发器实例幂等：客户端重建后绑定新 dispatcher，保留 module；失败注册可重试，并发注册同实例只执行一次。

最终验证：Core 相关回归 249 项通过；Mobile 纯 Kotlin/JVM 18 项通过；协议校验 72/72、工具测试 4/4；两仓 68 个文件一致。Kotlin 实际生成 203 页、202048 字节数据，Core 逐页 schema 校验与完整拼接后逐字节一致。当前源码 wheel 构建与源码外契约/网页/API 冒烟通过，前端未改，复用既有 V2 构建。

验证边界：没有完整 Python 全量测试、GitHub CI、Flutter/Android APK 编译或真机验收；JVM 测试覆盖隔离出的分页、观察参数与注册逻辑，不代表 Android 组件已经构建。两端完整分页与观察需部署本批配套版本；原调用格式保留。
