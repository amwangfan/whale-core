# 第 12 轮：完整观察、元素归一化与采集选项

Core observe 使用完整分页输出，提取独立观察解析器，支持 Agent2 的 captured_at、screen.w/h 和字符串 bounds，也保留已有平面尺寸和坐标数组格式。归一化后计算稳定 UI 签名；坏元素跳过并标记部分结果，重复元素 ID 或完全损坏的数据明确报错。缺少图片时不再用 UI JSON 伪装截图。

Mobile 增加可独立测试的 ObserveOptions；截图/UI 树开关与 max_elements 在真正采集前验证并生效，截图关闭时不采集，UI 树关闭时不要求可用窗口，数量不超过设备 400 元素容量。旧调用的默认行为保留。

验证：最终 Core 观察/输出/真实 WebSocket 适配回归 44 项通过，Mobile 观察策略 JVM 测试 4 项通过；包括真实手机形状的多页 UTF-8、坐标中心、元数据、异常数据及采集前参数拒绝。完整 Android 组件构建与真机验收仍待具备相应环境后执行。
