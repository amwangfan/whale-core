# 第29轮：按板块深入优化

## 本轮实际修改

**后台调用与记忆任务**：BoundedCall在提交外部调用前验证超时，错误参数不启动模型；构造参数同样检查平台等待范围。增加幂等close，关闭后拒绝新调用，已运行的调用自然完成。OwnerFactStack停止worker后关闭其持有的CompositeCallGate；外部注入的模型门不归它所有，不擅自关闭。Worker拒绝NaN/Infinity/布尔时间参数、负重试次数和小数重试次数，避免静默转换与不可用的租约。

**动作持久状态与清理**：终态保留期从终态落库updated_at计算，旧记录回退created_at；迟到真实回执不会刚落库就被清理。重复终态不刷新该时间，保持first-terminal-wins并防止无限续期。清理参数在事务前检查，异常时间转换不会中断整趟扫描。InMemory与SQLite同样验证。

**HTTP与设备输入**：抽取security.json_input统一两类入口。拒绝重复字段（含嵌套对象）、NaN/Infinity及溢出浮点数，保留普通JSON、Unicode和大整数精度。HTTP原错误返回与设备invalid_message语义保留，移除WebSocket重复解析函数。

## 验证与范围

模块回归144项通过；新增边界文件20项通过，包含在途模型调用关闭、无效参数不产生外部调用、宿主停止异常仍释放自有门，以及HTTP/设备共享解析。全量最终结果见本轮交付记录。没有修改手机生产代码、网页展示、服务地址、模型或密钥。
