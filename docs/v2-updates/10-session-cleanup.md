# 第 10 轮：按实际会话清理连接

同一设备的新连接替换旧连接后，旧连接退出此前仍会发布 device:offline。现在仅当退出的是在线表中的当前会话时删除并发布离线事件，保留替换后的新会话。

握手校验与 hello_ack 发送也纳入统一 finally 清理路径，避免已经登记设备、发送确认时断线而残留在线会话。

验证：4 项定向测试通过，覆盖正常断开、连接替换、确认发送失败和无效握手；连同前九轮及相关设备/通知测试，最终 165 项通过。Mobile 协议校验 72/72、工具测试 4/4，两仓 68 个契约文件一致。

当前源码 wheel 构建、源码目录外安装及 V2 契约/网页/API 冒烟通过；复用未改动的第 03 轮网页产物。

本次没有修改 Mobile Android 实现、重启用户服务或修改其配置。没有真机联调或 APK 构建结果。
