# 记忆图谱浏览

在本机控制台的「记忆」页选择一个群空间，即可查看二维图谱，并切换为 3D 星空。

支持拖动、缩放、旋转（3D）、节点选择与详情、关键词和事实状态筛选、手动刷新以及每 10 秒自动更新。自动更新在页面隐藏时暂停。筛选保留命中节点的相邻节点，便于查看来源。

## 数据含义

- 记忆节点：存储的摘要、状态、来源、时间、置信度。
- 人物节点：记录的 subject_id，不自动推断人物身份。
- 空间节点：记录所在的记忆空间。
- 证据节点：点击后按需加载对应群档案原话、发送者昵称和账号、北京时间、群号及完整消息 ID。只能查询所选记忆实际引用的证据；来源缺失或不支持时明确提示，不以摘要冒充原话。旧导入每条最多保留 4000 字，图片和语音不转录。
- 连线：包含、主体、依据、依赖、更正为。只映射存储字段，不产生新的关系推断。

状态显示存储状态，另列 expires_at；active 记录仍可能因过期、权限或激活判断而不进入回答。图谱不是本轮召回轨迹。

## 接口与范围

`GET /api/v1/studio/memory/graph?space_id=...`

`GET /api/v1/studio/memory/evidence?record_key=...&evidence_id=...`：沿用管理鉴权，检查记忆及证据引用后，以群号和消息 ID 精确读取本地归档。

沿用管理 API 的 Bearer 鉴权。群记忆空间中的画像与显式喜好由管理界面查看。受保护原始库拒绝进入此图谱。单次展示一个空间的最新 300 条记忆，并明确报告截断；不会画指向本次数据范围外记录的连线。

选择群空间后，「群聊关键词」从该群分段索引统计同段出现的词对。首页展示覆盖段数最多的 80 个关键词，可用搜索框查找其他词。点击关键词可看各段的命中发言、发送者、时间，或展开整段上下文。

「导入 MCP 图谱」可选择或拖入 JSON / JSONL 文件，也可粘贴文本。支持 entities / relations 对象、实体与关系数组、逐行 entity / relation 记录。实体详情显示 observations。文件上限 8 MiB，预览保存在当前组件内，离开页面或切换空间即清除。搜索在完整导入数据中执行，单次画布最多展示 1000 个节点。

实体类型和关系类型筛选在二维、三维共用。「切换 3D 星空」后，勾选「3D 性能」可查看实测 FPS、平均帧间隔、绘制调用、三角形及可见节点和关系数。

## 实现

- `api/studio/memory_graph.py`：只读投影。
- `web/src/components/MemoryGraph.tsx`：二维布局、筛选与详情。
- `web/src/components/MemoryGraph3D.tsx`：延迟加载的 3d-force-graph 渲染。

图谱展示不调用模型，不向外部服务上传记忆。依赖打包到本地静态资源。
