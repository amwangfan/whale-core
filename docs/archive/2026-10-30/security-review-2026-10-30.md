# 安全复核（2026-10-30）

范围：Shell 执行、模型 HTTP 传输、网页/产物抓取，以及管理 API、配置、插件生命周期与任务编排的独立代码复核。复核包含真实本地进程和本地 HTTP 服务，不包含付费服务、生产账号或真实设备调用。

## 本轮直接修复

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| Shell 完整收集输出后再截断，可能耗尽内存 | selectors 增量读取、有限前缀缓存、总输出字节上限、超限强杀 | 无限输出进程返回 `output_limit`，缓存保持有界 |
| Shell 默认共享 `/tmp` 与缺少系统隔离 | 默认 Bubblewrap；独立命名空间、无网络、仅授权工作目录可写、只读运行库、私有临时目录 | 参数与拒绝路径自动测试；本环境命名空间受限制，未取得隔离成功运行证据 |
| Shell 资源与身份转换失败不完整 | prlimit 硬资源限额；原生 Popen 降权参数；明确不可用回执 | root 容器缺权限时返回错误，不再抛未捕获异常或伪装执行 |
| 模型 HTTP 默认跟随重定向，可能跨源发送 Authorization | 禁止所有模型端点重定向 | 两个本地 HTTP 服务：源返回 302，目的服务收到请求数为零 |
| 模型响应读取无大小上限、异常分类不完整 | 最大 2 MiB；UTF-8、JSON、网络与结构错误明确分类 | 超限读取、非法编码、无效端点与 HTTP 错误回归 |
| 网页抓取环境代理使 peer 校验观察到代理而非真实目标 | 默认禁用 HTTP(S)_PROXY，网页与产物下载直连 | 同时设置大小写代理变量，确认不安装 ProxyHandler；逐跳 SSRF 防护保持 |

## 集成复核关注点

发现并交由集成负责人处理：插件启用失败仍返回成功、插件禁用后保留静态工具/模型引用、设置保存未实际重装配、任务审批与继续执行的区分、并发会话/审批/任务索引、热更新对执行中任务的影响、私有数据库权限以及静态资源的浏览器安全响应头。

插件禁用的候选实现已复核：运行时工具和模型必须动态查询启用注册表；读取已保存配置并不能证明该能力目前启用。对外状态同样应反映启用注册表，不能把“代码存在”显示为“能力可用”。

## 部署验收边界

- 必须在目标 Linux 主机以非 root 专用用户完成 Bubblewrap 正向验收；本轮没有证明当前托管环境支持用户命名空间。缺少依赖、namespace 被禁用或降权失败均拒绝执行，不自动降级。
- `sandbox="disabled"` 只适用于维护者明确选择的可信宿主命令，不构成隔离边界。
- 默认安全抓取不经过环境转发代理；必须使用代理的部署需额外设计可证明目标地址的传输层。
- 真实模型、媒体供应商、QQ、手机、眼镜及电话链路分别需要真实凭据和设备验收；离线合同测试与本地 HTTP 测试不代替这些验收。

## 最后一次集成复核

独立回归文件 `tests/test_final_security_review.py` 验证了以下真实边界：

- 初始化实时语音会话失败时，尚未被会话桥接管的连接也会关闭；关闭失败不会泄漏上游错误原文。
- 公共配置投影写入失败时，重启读取的 endpoint 和 API key 仍来自同一私密原子快照；读取有效环境时也只读取一次快照，避免跨代组合。
- 非法 JSON 的语音开会话请求返回 400，供应商打开会话计数为零。
- 从真实管理 API 提交的 ASR 原始音频只到达工具处理器，原始字节和 base64 均不进入任务日志、记忆或响应；完成后临时输入释放。
- 不同 Outbox 实例共享全局主动暂停状态；暂停后真实出站端口调用数为零。
- 通过真实管理 API 打开的语音会话收到持久化人格、近期记忆和本次补充说明，全程不调用文字模型。接收重复的最终转写会去重，只保存用户和助手最终文本，不保存音频 delta。

最后审查还推动了配置更新与工作流/任务创建的锁协调、旧运行根注册表撤销和原生语音人格/文本记忆接线。这里的“真实管理 API”指本机 HTTP 服务与测试供应商传输，不能当作外部供应商或真机联调证据。
