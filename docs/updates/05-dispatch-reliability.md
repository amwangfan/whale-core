# 第 05 批：请求发送与连接可靠性

状态：定向及联合验证完成。日期：2026-11-07。

## 修复

- Core 和 Mobile 参考网关在登记等待项、占用动作幂等键之前，复用现有协议校验请求。非法参数不会把幂等键永久占住，修正参数后可继续使用原键。
- 明确拒绝无效超时、空字符串或错误类型的显式幂等键；省略键仍保留自动生成行为。
- 每条连接用发送锁把“分配序号、构造帧、发送”串起来，避免并发发送时序号与实际顺序倒置。
- Core 的动作记录和请求使用同一份过期时间，减少边界偏差。
- 已进入真实发送路径的未知结果仍保留原幂等预约，不把“网络错误”当成“未执行”后自动重放。

## 验证

新增 Core 12 项边界/并发测试；Mobile 参考网关回归通过。联合入口涵盖 Core 176 项、Mobile 22 项测试，另有协议 20/20 与 36 文件镜像检查。最终结果以本地集中日志为准。

本批未改协议、既有能力或授权范围，不替代真机和 APK 验收。
