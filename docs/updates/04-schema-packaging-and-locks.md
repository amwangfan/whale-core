# 第 04 批：协议校验、安装包与跨平台锁修复

状态：本机验证完成。日期：2026-11-07。

## 改动

- 协议校验器递归检查全部 Schema 节点，不再静默忽略嵌套未知规则；落实对象字段数量、附加属性校验及 JSON 数字/布尔值相等语义。
- 增加 39 项标准 JSON Schema 对照与协议边界测试，现有协议内容不变。
- wheel 携带 canonical 协议快照，运行时优先查找包内协议；构建暂存和冻结包参数同步携带协议。
- 修复构建脚本因仓库没有可选 `licenses/` 目录而直接失败的问题；目录存在时仍完整复制。
- QQ CLI 复用跨平台单实例锁，不再在 Windows 上无锁启动；正常结束和异常退出都释放锁。
- Linux Shell 专用集成测试明确标注运行平台，修复 Windows 收集阶段直接调用 `os.geteuid` 的错误；不把 Linux Shell 功能改为无隔离 Windows 执行。

## 验证

- Schema、QQ 与进程锁定向测试：53 通过、1 个 POSIX-only 测试跳过。
- 五阶段跨仓联合检查通过；协议 36 文件一致，Mobile 协议 20/20、对端与工具 20 项通过。
- 已实际构建带控制台的 wheel，在源码目录外安装，验证包内协议、控制台首页和带鉴权 API。
- Windows 全量检查尝试：停止时 802 项通过，7 失败、1 错误；其中 QQ 无锁问题已修复。剩余发现涉及 POSIX 权限位、Linux 路径与符号链接特权，未通过放宽断言宣称全量通过。Linux 全量、APK 与真机验证仍待相应环境执行。
