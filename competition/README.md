# Whale — More Than an Agent | LifeHack 参赛原型

本目录独立于正式控制台，所有示例记忆均为虚构；不存在真实家庭设备访问。核心价值：同一个人格，改变其记忆和能力，观察不同的回复与行动。

## 本地体验

从仓库根目录运行：
- 离线预设（不需要 Python 包或模型）：`python -m http.server 8765 --bind 127.0.0.1 --directory competition`
- Core 真实召回 + 模型：`python -m pip install -e .`，设置环境变量 WHALE_DEMO_BASE_URL（OpenAI 兼容、含 /v1）、WHALE_DEMO_MODEL、WHALE_DEMO_API_KEY，再运行 `python competition/server.py`。
- 浏览器打开 http://127.0.0.1:8765/ 。
- 后端单元测试：`python -m unittest discover -s competition -p 'test_*.py'`。

## 评委 3 分钟体验（5 步）
1. 在深夜搭档世界点击「我回来了，今天有点累」。
2. 点击回复里的 N1/N2 或记忆节点，再切换到关系图；切换创作同伴、温柔室友并重发同样的句子。
3. 点击「打开台灯」：未授权时状态不变，产生拒绝回执。
4. 将台灯卡拖到能力槽（手机可点击装备），重新请求：房间点亮；切换创作同伴再打开台灯，可看到白光。
5. 装备扫地机器人及窗帘，启动清扫/打开窗帘；撤销卡牌后再请求，检查拒绝回执；重置体验。

## 技术边界
- Python 预览服务真正复用 Core InMemoryStore、MemoryCurator、apply_memory_budget；不读取 ~/.whale，也不修改正式服务。仅允许当前模拟空间召回。
- 注入记录/评分是实际召回；句子到记忆是模型自报语义关联（ID 已校验），非因果证明。离线模式则显示预设关联。
- 设备授权是浏览器内作用域，执行器白名单与当前授权共同决定数字孪生状态；模型不能自行授权。模型可提议白名单动作；只有模拟执行回执表示状态变化。
- 三个世界分开保存对话（仅内存）；切换时丢弃在途旧回复；设备授权和虚拟家庭在同一次体验内共享。
- 本地 HTTP 服务只监听回环地址，不是面向公网的生产服务。不应直接公开生产管理 API 或模型密钥。
- 当前模型接入采用 OpenAI 兼容 HTTP；未调用完整 WhaleCompanion 路径，也未连接 whale-mobile 真机。离线场景是脚本而非真实模型。

## 验收重点
三种记忆同问不同答；无跨世界记忆引用；点击句子/记忆双向高亮；未装备拒绝、装备成功、撤销后拒绝；模型不可用时明确降级；快速切换无旧结果污染；评委不登录、不需要 API key。真实模型及公网部署仍待联调。
